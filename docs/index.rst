sphinx-sbom-generator documentation
============================

.. toctree::
   :maxdepth: 2
   :caption: Contents

   sbom

The ``sbom.md`` file is generated by running ``sphinx-sbom-generator`` against
the project's manifests. It is intentionally not committed to the
repository — instead it is built fresh as part of the documentation
pipeline so it always reflects the current dependency set.

To produce it locally::

    sphinx-sbom-generator -r requirements.txt -p package.json -o docs/sbom.md
    sphinx-build docs docs/_build
